# 32-bit RISC-V Processor

## Overview
This project implements a simple 32-bit RISC-V processor using Verilog HDL in Vivado.

## Modules
- ALU
- Register File
- Instruction Memory
- Data Memory
- CPU Top Module

## Tools Used
- Vivado 2023.1
- Verilog HDL
